# C2KV 实验记录 0723

本文整理 7.23 围绕工具定义 KV 复用 baseline、标准 Hybrid 和 Aug Hybrid 的公平子集对比结果。实验使用同一批公共有效样本统计，避免不同方法由于 OOM、长度过滤或解析失败导致样本集合不一致。本节结果暂不纳入 `cacheblend_recompute_ratio=0.3` 的额外实验。

## 1. Reuse Baseline 与 Hybrid 变体对比

实验设置：

- 公平对齐公共子集：Valid = 79。
- 平均当前 prompt 长度：Avg Prompt = 4423 tokens。
- Router：top-k = 3，lexical router。
- CacheBlend：本表仍采用主实验配置 `cacheblend_recompute_ratio=0.15`。
- 标准 Hybrid：`top-k full tool schemas + rest compressed tool schemas`。
- Aug Hybrid：`all tool schemas compressed + extra top-k full tool-schema prefix`。

## 2. 主要观察

标准 C2KV Hybrid 仍然是当前质量最强的方法：工具名准确率达到 69.62%，高于 full、纯 C2KV、纯 SnapKV 以及其他 Hybrid baseline。这说明在该公共子集上，保留 router 选中的 top-k 工具完整 schema，对工具选择质量有明显帮助。

`cacheblend_vdiff_snapkv_hybrid` 修正后相比之前明显回升：工具名准确率达到 60.76%，和 `cacheblend_vdiff_snapkv` 持平，同时工具调用率从 60.76% 提升到 62.03%，TTFT 也从纯 CacheBlend 的 0.737s 降到 0.285s。这个结果说明标准 Hybrid 对 CacheBlend 并非一定有负面影响，之前下降更可能来自实现/位置处理或单次实验波动。

SnapKV 的标准 Hybrid 仍没有带来质量提升：`snapkv_hybrid` 的工具名准确率为 56.96%，低于 `snapkv_reuse` 的 59.49%。这说明简单把 top-k full 前置、其余工具用 SnapKV 压缩，对 SnapKV 本身不一定更友好。

Aug Hybrid 的质量改善不稳定。`cacheblend_vdiff_snapkv_aug_hybrid` 的工具调用率达到 63.29%，但工具名准确率为 59.49%，仍低于标准 `cacheblend_vdiff_snapkv_hybrid` 的 60.76%，且 TTFT 上升到 1.038s。额外拼接 top-k full 前缀会带来更多上下文信息，但成本和干扰也更大。

## 3. 对比口径说明

这组结果应主要看 `common_subset_results`，而不是每个方法各自的 `results`。`common_subset_results` 使用所有 present mode/ratio 的有效样本交集，因此 Valid = 79 是所有方法共同可比较的样本数。

标准 Hybrid 和 Aug Hybrid 回答的是两个不同问题：

| 变体 | 上下文结构 | 主要验证问题 |
|---|---|---|
| 标准 Hybrid | system -> top-k full -> rest compressed -> query | 将高相关工具保留为 full、其余压缩是否优于统一压缩 |
| Aug Hybrid | system -> all tools compressed -> top-k full -> query | 在不删除压缩上下文中 top-k 信息的情况下，额外 full top-k 是否带来增益 |

因此 Aug Hybrid 不是严格同压缩率对比。它多拼了一份 top-k full 工具前缀，实际压缩比会下降，TTFT 也会增加；它更适合作为“高精度 top-k 前缀是否有效”的诊断实验。

## 4. 当前结论

当前结果继续支持 C2KV Hybrid 作为主方法：它在工具名准确率和工具调用率上最强，说明 router 选择的高相关工具 full 保留与 C2KV rest 压缩的组合更适配当前任务。

CacheBlend 标准 Hybrid 在修正后已经不再明显下降，质量接近纯 CacheBlend，并且延迟更低；但 Aug Hybrid 的收益仍不稳定。后续可以继续单独扫描 `cacheblend_recompute_ratio`，但 0.3 的结果需要先排查稳定性后再纳入主表。
